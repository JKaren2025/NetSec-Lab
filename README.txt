ACADEMIA DE SEGURIDAD DIGITAL — ARCHIVOS DEL SITIO

Estructura:
- index.html
- correo.html
- css/estilos.css
- js/script.js

Para probar localmente:
1. Extrae esta carpeta.
2. Abre index.html con Live Server en Visual Studio Code.
3. La actividad de correo se abre desde la tarjeta "Seguridad del correo electrónico".

Para actualizar GitHub Pages:
1. Entra al repositorio de GitHub.
2. Abre la pestaña Code.
3. Sube/reemplaza index.html, correo.html y las carpetas css y js.
4. Confirma los cambios con Commit changes.
5. Espera la publicación de GitHub Pages y abre el enlace del sitio.

Nota: El diseño es original e inspirado en patrones generales de plataformas educativas: navegación superior, aviso, hero, composición fotográfica, estadísticas y tarjetas. No utiliza logotipo ni identidad oficial de Cisco. La actividad de correo es ficticia, no envía mensajes ni recopila contraseñas o datos personales.
